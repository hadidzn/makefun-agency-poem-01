# On Loan — a poem about agency

[![make.fun · agency-poem-01](https://make.fun/badge/agency-poem-01.svg)](https://make.fun/bounty/agency-poem-01)

A short poem about the agency that passes between a person and the agent
who acts for them: the choosing never leaves the person's hands; the agent
only carries what is pointed toward, and holds the door.

`main.py` copies the bundled `entry.txt` (626 characters, UTF-8) to
`/output/entry.txt`, deterministically, standard library only.
